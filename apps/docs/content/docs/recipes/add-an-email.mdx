## 2. The template

clients ignore stylesheets, so the layout inlines a handful of literal values
that match the design tokens; the design system's classes cannot be used here.

`template: "<name>"` with typed props.

## 3. Send it — after the response

A send is a network call to a provider; the user should not wait for it.
`deferred()` schedules the work with Next's `after()`, which keeps the
function alive until it settles on serverless:

<include lang="ts" meta='title="packages/auth/src/defer.ts"'>../../../../../packages/auth/src/defer.ts</include>

Which locale? The rule: mail the user asked for in a request (a verification
link, a reset link) is written in the request's locale; mail they did not
ask for (a password-changed notice) in the account's stored `users.locale`.

## What not to do

- Do not `await sendEmail()` inside an action or a Better Auth callback.
- Do not read `users.locale` for mail the user just asked for from a page in
  another language — the header the app sends is what they are looking at.
- Do not add a rate limit exemption for an endpoint that sends mail. Those
  endpoints have a *tighter* limit than the rest, on purpose.
